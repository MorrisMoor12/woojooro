# 나레이션 오디오

씬별 TTS 파일을 여기에 넣으세요. 파일명 = 씬 순서입니다.

| 파일 | 씬 | 대사 |
|------|-----|------|
| `tts01.wav` | 1 훅 | "서울 사장님 한 명당 빚, 얼마일 것 같으세요?" |
| `tts02.wav` | 2 카운트업 | "4억 8천만 원. 전국 평균보다 1억 4천만 원 더 많습니다." |
| `tts03.wav` | 3 지도 | "서울만? 아닙니다. 수도권 전체가 빨간불입니다. 경기 3억 7천, 인천 3억 4천." |
| `tts04.wav` | 4 바레이스 | "게다가 문제는 속도입니다. 지난 2년간 서울 8.3% 급증. 평균의 두 배." |
| `tts05.wav` | 5 게이지 | "못 갚는 대출이 1년 새 50% 급증. 가장 위험한 건, 의외로 20대 사장님." |
| `tts06.wav` | 6 폐업 | "2025년 폐업한 가게 97만 곳. 열 곳 중 한 곳이 문을 닫았습니다." |
| `tts07.wav` | 7 해법+CTA | "살아남는 사람들은 딱 세 가지. 댓글에 업종만 남겨주세요." |

## 넣은 뒤

```bash
npm run measure-audio   # 각 파일 길이를 재서 씬 길이를 자동 조정
npm run dev             # 미리보기로 싱크 확인
npm run render          # 최종 렌더
```

`.wav` / `.mp3` 모두 가능하지만, 파일명은 위 표대로(`tts01`…`tts07`) 맞춰주세요.
다른 이름을 쓰려면 `src/audio/scenes.json`의 `file` 값을 바꾸면 됩니다.
